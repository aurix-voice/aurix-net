# Aurix Net — Unreal Engine plugin

Unreal NetDriver over Aurix relay rooms plus a Blueprint subsystem for rooms, grants and events.
See [Docs/QuickStart.md](Docs/QuickStart.md). Engine 5.3–5.8; Win64, Linux, Mac, Android.

Status: beta — the relay NetDriver and subsystem are here; sync and lockstep components and an
Online Subsystem (sessions / matchmaking through the standard nodes) follow.
